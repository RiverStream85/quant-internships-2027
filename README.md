# Quant Internship Tracker 2027

## Open the website

### [Launch the Quant Internship Tracker](https://riverstream85.github.io/quant-internships-2027/)

The site is public and works on phones and computers. Use the **Women’s programs** tab for women-focused winternships and insight programs, or search the complete TraderMath firm directory by company and interview style.

## What is included

- Verified Summer 2027 and Winter 2027 internship application links
- A dedicated women’s-program section, including VIRTU’s location-specific applications and HRT WiTTI monitoring
- Program dates and application deadlines when the employer publishes them
- Coding-heavy, math/reasoning-heavy, mixed, or insufficient-evidence interview classifications
- A short TraderMath-based interview summary and TraderMath guide link for every firm

## Weekly update schedule

The tracker is automatically checked and republished **every Monday at 10:17 AM Asia/Shanghai time**. The date of the last successful check is shown at the top of the website.

[View weekly update history](https://github.com/RiverStream85/quant-internships-2027/actions/workflows/weekly-refresh.yml)

The automated check refreshes current official ATS listings, cross-checks the current InternAtlas feed, tests existing application links, and rebuilds the site. Job boards can change between checks, so always reopen the employer’s application page before applying.

## Data and methodology

- [`quant_internships_2027.json`](quant_internships_2027.json) — structured tracker data
- [`quant_internships_2027.md`](quant_internships_2027.md) — readable full report and methodology

The company universe comes from [TraderMath’s firm directory](https://www.tradermath.org/practice/firms). “No verified opening found” means the latest audit did not find a qualifying current posting; it does not mean the company is confirmed closed.
