# Quant Internship Tracker 2027

This folder is ready to use as a small static website.

## View it locally

Double-click `index.html`. Search, filtering, applications, and interview links work without installing anything or running a local server. Links now open in the same tab for compatibility with local-file viewers. Use the **Women’s programs** tab for women-focused winternships and insight programs; it separates live 2027 applications from programs that only have a monitoring page. VIRTU appears once there with separate New York, Dublin, and Singapore application buttons.

## Publish it with GitHub Pages

1. Create a new public GitHub repository, for example `quant-internships-2027`.
2. Upload every file in this folder to the repository root and commit them to the `main` branch.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then save.
6. GitHub will publish the site at `https://YOUR-USERNAME.github.io/quant-internships-2027/`.

Official instructions: <https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site>

## Updating the data

Replace `index.html`, `quant_internships_2027.json`, and `quant_internships_2027.md` with regenerated versions, then commit and push. GitHub Pages will redeploy automatically.

## Important

The research snapshot is dated 2026-08-24. It covers all 273 firms in TraderMath’s directory and currently surfaces 221 unique application links across 37 firms, plus a dedicated women’s-program section. “No verified opening found” means the expanded audit did not find a qualifying current posting—it does **not** mean the firm is confirmed closed. Internship postings can change without notice, so application links should be rechecked before sharing an update.
